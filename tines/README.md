# Tines Playbooks

This directory contains importable Tines Stories for common investigation and enrichment tasks. Every playbook folder includes a `playbook.json` template, a workflow diagram, and documentation for the workflow.

| Playbook | Description |
| --- | --- |
| [IP Enrichment](ip-enrichment/) | Enriches public IPv4 addresses through configured reputation and intelligence providers. |
| [URL Enrichment](url-enrichment/) | Normalizes and enriches URLs with URLScan.io, VirusTotal, and related sources. |
| [ANY.RUN URL Analysis](anyrun-url-analysis-ai-summary/) | Runs submitted URLs in ANY.RUN and returns a concise analysis result. |
| [ANY.RUN File Analysis](anyrun-file-analysis-ai-summary/) | Runs submitted files in ANY.RUN and reports the result. |
| [Brand Monitoring Using OCR](brand-monitoring-ocr/) | Screenshots suspicious sites and compares visual evidence with a brand-protection context. |
